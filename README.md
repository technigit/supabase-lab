## Supabase Lab
Supabase Lab is a command-line client environment for experimentation and development, implemented in Python and in Node.js.

It allows experimentation with many aspects of Supabase, such as real-time capabilities, authentication and authorization, storage, API functions, edge functions, database operations, testing and debugging, performance monitoring, analytics, etc.

## Prerequisites
* Python 3.0+
* Node.js 22.0+

## Notes
* This project is currently in a learning/experimental phase.  As such, many features may have not been implemented yet.

* New experimental features usually start out in the dev area, and they will be moved into the main code area after they stabilize.

## Contributing
Contributions are welcome and encouraged!

* __Create a branch__:  Work in a branch that corresponds to the programming language you are using.  Currently, we have branches for Python and JavaScript.

* __Add an experimental feature__:  If you want to add an experimental feature, such as a command-line for a new concept in interacting with Supabase, please start in the dev area (e.g., dev.py or dev.js).  When the new feature is reasonably settled, useful, and documented, it may be merged in with the main features.

* __Add a new language__:  If you want to add support for a new programming language, feel free to create a new branch for it!

* __Submit a pull request__:  Once your changes are ready, submit a pull request for review.

Contribution Guidelines:

* Please do your best to follow the project's coding standards.

* Write clear, concise, and descriptive commit messages.

* As much as possible, please submit code that works without crashes or error messages.
